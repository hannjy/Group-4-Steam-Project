\hfill\break

We chose to work on the Steam Games Dataset 2025. From this, we selected
the games\_march2025\_cleaned subset to explore and use for our
projects.\\
\strut \\

The dataset was sourced from Kaggle, where the data was created with
Steam store page scraping and Steam Games Scraper repository, which
gathers data using the Steam API and Steam Spy. It consists of all the
games available on the digital gaming distribution platform steam in
March of 2025, and provides extensive information about each individual
game.\\

  This was of interest for us because we thought that the game data
could help to build informative analysis that tells a story and shows
insightful correlations. We are able to conduct both broad and specific
analysis which gives us a-lot of material to work with for answering
specific questions.\\

It consists of 89,618 rows, one per Steam application identified by
\texttt{appid}, and is cross-sectional as each game is observed once at
the March 2025 collection date. The variables are mixed: continuous and
discrete numerical measures such as \texttt{price},
\texttt{pct\_pos\_total} and count variables like \texttt{dlc\_count}
and \texttt{peak\_ccu}; binary (\texttt{windows}, \texttt{mac},
\texttt{linux}); ordinal bins (\texttt{estimated\_owners}); nominal
fields stored as lists (\texttt{publishers}, \texttt{genres},
\texttt{categories}, \texttt{supported\_languages}); and unstructured
text.\\

Explicit missingness is minimal, under 1\% for every retained variable,
the largest being \texttt{categories} at 0.9775\% empty and
\texttt{publishers} at 0.6104\%. However, missingness is instead encoded
through sentinel values which will be addressed during EDA.\\

We only used the games\_march2025\_cleaned subset of the Steam Games
Dataset 2025, and did not include any of the data from the other
subsets.
